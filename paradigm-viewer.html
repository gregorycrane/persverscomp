Reading the grid

Choose a paradigm first. The viewer opens the three most frequent compatible stemtypes as parallel columns. As in the main PMV reader, every column has its own selector, so it can be changed independently; add or remove columns as needed, up to six. Verbs use tense–mood–voice paradigms; nouns and adjectives use declensional slots. Participles remain verbal stemtypes but use number–case–gender rows. Each cell ranks attested surface forms, initially showing only the most frequent. Counts combine registered treebank morphology with compatible Morpheus analyses.
